## How To Use This File

This HQ file is Claude's table of contents for the entire vault.

When Claude starts a session, it reads:
1. Session_Log.md (changes since last chat)
2. This HQ.md (vault map)
3. The protocol relevant to today's task

Every file in the vault should be linked from somewhere in this HQ.
If a file isn't reachable from HQ, Claude won't find it.
