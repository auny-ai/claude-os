# Session Log

*Running log of vault changes across all chats. Every session that creates, edits, or deletes vault files appends an entry here. Every new session starts by reading this file.*

---

## How This Works

- **Any chat that modifies the vault** appends an entry here
- **Every session starts by reading this file** — first thing after HQ
- **Format:** date · context/project · what changed · why

---

### [YYYY-MM-DD] — [Session Topic]

- Created `path/to/file.md` — [one-line reason]
- Updated `path/to/other_file.md` — [one-line reason]
- Deleted `path/to/old_file.md` — [one-line reason]

**Discovered / Decided:**
- [Anything important that came up but isn't a file change]
